# sealjar demo

Capture the bundled bakery and try detecting a changed screenshot

## Usage

```
sealjar demo
```

## Examples

```
sealjar demo
sealjar demo --out ./bakery-demo --json
sealjar demo --dry-run
```

## Flags

- `--out` Write demo packages and reader folders here

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.

## Related commands

- sealjar capture
- sealjar verify
- sealjar report
