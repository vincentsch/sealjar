# sealjar demo

Capture the bundled bakery and try detecting a changed screenshot

## Usage

```
sealjar demo
```

## Examples

```
sealjar demo
sealjar demo --out ./bakery-demo --json
sealjar demo --dry-run
```

## Flags

- `--out` Write demo packages and reader folders here

## Output

Defaults to human-readable output. Use `--json` for JSON.

## Preview changes

`--dry-run` previews changes without writing files.

## Related commands

- sealjar capture
- sealjar verify
- sealjar report
