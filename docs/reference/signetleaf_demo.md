# signetleaf demo

Capture the bundled bakery and try detecting a changed screenshot

## Usage

```
signetleaf demo
```

## Examples

```
signetleaf demo
signetleaf demo --out ./bakery-demo --json
signetleaf demo --dry-run
```

## Flags

- `--out` Write demo packages and reader folders here

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.

## Related commands

- signetleaf capture
- signetleaf verify
- signetleaf report
