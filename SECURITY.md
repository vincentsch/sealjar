# Security

Please report security issues privately. Use
[GitHub private vulnerability reporting](https://github.com/vincentsch/sealjar/security/advisories/new)
if it is enabled for the repository. You can also email
`vschmalbach@vschmalbach.com`.

Do not open a public issue for a vulnerability before a fix is available.
Do not include credentials, captured private content or unredacted packages in
public reports. Describe the issue with a small example using fake data.

Sealjar is pre-1.0. Security fixes may ship as patch releases without
preserving behavior that caused the issue.
