§ 5 {{index .Sections 5}}

{{if eq .Lang "de"}}

Die Erfassung wartet höchstens 30 Sekunden auf das Laden und eine Sekunde Netzwerkruhe, scrollt für nachgeladene Bilder und kehrt nach oben zurück. Nach dem Scrollen wartet sie höchstens zehn Sekunden auf Netzwerkruhe. Sie klickt keine Elemente an. Pro Bildschirmfoto werden höchstens 20.000 CSS-Pixel Höhe erfasst. Zeitlimits und Kürzungen stehen bei der jeweiligen Seite.

HTTP-Basisauthentifizierung: {{if .M.Settings.BasicAuth}}verwendet{{else}}nicht verwendet{{end}}. Manuelle Anmeldung: {{if .M.Settings.ManualLogin}}verwendet{{else}}nicht verwendet{{end}}. Zugangsdaten werden nicht in den Bericht übernommen.

Passende Prüfsummen zeigen, dass die Dateien mit dem Manifest übereinstimmen. Das allein authentifiziert das Manifest nicht. Ein unabhängiger Zeitnachweis erfordert einen Zeitstempel einer unabhängigen, vertrauenswürdigen Zeitstempelstelle. Zeitstempel mit dem öffentlichen Demo-Schlüssel liefern keinen unabhängigen Zeitnachweis, auch bei ausdrücklich gewährtem Vertrauen. Die Vertrauensprüfung erfolgt über SEAL.html und sealjar verify. Sie belegen weder wahre oder vollständige Inhalte noch deren Herkunft vom Server: HTTPS liefert keine Serversignatur über diese Dateien. Sie belegen keine ehrliche Bedienung, Abnahme oder Lieferung. Ob der Code die Website erzeugt hat, bleibt offen.

Bei wichtigen Streitfällen empfiehlt sich eine neutrale Begleitung, etwa durch einen Sachverständigen oder Notar. Eine Offline-Prüfung erkennt spätere Zertifikatswiderrufe nicht. Sealjar bewertet keine eIDAS-Qualifikation.

{{else}}

Capture waits up to 30 seconds for loading and one second of network idle, scrolls to load images, then returns to the top. After scrolling it waits up to ten seconds for network idle. It does not click elements. Screenshots stop at 20,000 CSS pixels in height. Each page lists timeouts and truncation.

HTTP basic auth: {{if .M.Settings.BasicAuth}}used{{else}}not used{{end}}. Manual login: {{if .M.Settings.ManualLogin}}used{{else}}not used{{end}}. Credentials are omitted.

Matching hashes show agreement with the manifest. They alone do not authenticate the manifest. Independent time evidence requires a timestamp from an independent trusted authority. Tokens signed with the public demo key provide no independent time evidence, even when explicitly trusted. Check timestamp trust in SEAL.html and sealjar verify. They do not show that content is true or complete, that the server sent these bytes (HTTPS has no server signature), that the operator was honest, that work was accepted or delivered, or that captured code produced the website.

For important disputes, consider having a neutral expert or notary present during capture. Offline checks cannot see later certificate revocation. Sealjar does not assess eIDAS qualification.

{{end}}
